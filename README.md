# Banking-Queue-Simulator
## Description
This is a Java-based Banking Queue Simulator that demonstrates queue operations in a banking system. It simulates customers entering a queue and being served in a First In First Out (FIFO) manner.

## Features
- Add customers to the queue
- Serve customers in FIFO order
- Display the queue status
- Simple console-based interface

## Technologies Used
- Java
- Queue Data Structure

## How to Run
1. Compile the program:
   javac BankingQueueSimulator.java

2. Run the program:
   java BankingQueueSimulator
